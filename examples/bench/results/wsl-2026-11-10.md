# WSL での gowaku の参考値（2026-11-10）

[docs/BENCH.ja.md](../../../docs/BENCH.ja.md#linuxwslの参考値) の生データと手順。

- 環境: Windows 11 の WSL2（Ubuntu 24.04）、i7-12700H。headless sway 1.9（`WLR_BACKENDS=headless`、`WLR_RENDERER=pixman`、出力 1280×800）。Vulkan は lavapipe。
- バイナリ: `GOOS=linux CGO_ENABLED=0 go build -ldflags="-s -w"` の `examples/bench/gowaku` と `examples/hello`。
- 起動: `gowaku -scenario startup` が READY を書いて終わるまでを、`date +%s%N` の差で 7 回測った。
- 他のシナリオ: `-duration` で走らせる。CPU は `/proc/<pid>/stat` の utime + stime の差を、開始 2 秒後から終了 1 秒前までの壁時計で割った。fps は `-out` のフレーム時刻を同じ区間で数えた。

```
binary gowaku=9806087 hello=9408775
startup 204
startup 166
startup 164
startup 169
startup 155
startup 158
startup 165
animate fps=59.0 cpu=190.9%
dense fps=59.0 cpu=101.5%
dense-flat fps=59.0 cpu=284.1%
idle fps=0.0 cpu=0.0%
```

スクリプト: [wsl.sh](wsl.sh)。sway は [scripts/wsl/sway.sh](../../../scripts/wsl/sway.sh) で起動し、[getdebs.sh](../../../scripts/wsl/getdebs.sh) が `~/lx` に展開した deb を使う。
