# 0125: 文字の切り詰め（MaxLines）、飾りの文字を Semantics から外す ExcludeSemantics、VStack/HStack の既定の間隔

決定日: 2026-11-16

状態: 採用

## 背景

初めて使う人に gowaku を試してもらったところ、次の 3 つが見つかった。

1. **文字を N 行で切り詰める方法が無い。** 一覧の行に 1 行だけ出すプレビューや、カードに 2 行だけ出す説明を作るとき、利用者は幅を推測して文字列を切っていた。フォント、DPI、言語が変わればずれ、書記素クラスタや BiDi も壊れる。
2. **飾りの文字をスクリーンリーダーから隠せない。** アバターの頭文字「S」が、名前の隣で Semantics ツリーに text ノードとして入る。`basic.Icon` と `basic.Image` は `Label` が空なら飾りとして外れるが、`Text` には同じものが無い。
3. **`basic.VStack` / `basic.HStack` は子の間を空けない。** グループとボタンを積んだレシピが詰まって見え、利用者は `basic.Column{Size: MainMin, Cross: CrossStart, Spacing: ...}` に書き換えていた。godoc は「SwiftUI のスタックのように」と書いていたが、SwiftUI のスタックは既定で子の間を空ける。

## 選択肢

### 1. 切り詰め

- **(a) 部品の側（`basic.Text`）で、測って文字列を切ってから組み直す。** 組版を 2 回行い、ルビ・縦書き・BiDi の規則を部品の側でもう一度持つことになる。`text` を直接使う人には届かない。
- **(b) `text` の行分割に入れ、`text.Style.MaxLines` で指定する。** 行の位置、クラスタ、BiDi の並べ替え、縦書きの字形をすでに持っている所で処理できる。`Style` に入るので `SameLayout` の比較に自動で加わり、テーマのスタイルにもそのまま付けられる。

最後の行の切り方も 2 通りある。

- **(i) 普段どおりに改行した最後の行の後ろに「…」を付ける**（CSS の `line-clamp` に近い）。英文では単語の境目で終わるが、行が短く残ることがある。`MaxLines: 1` で「幅で切る」にならない。
- **(ii) 最後の行には、そのブロックの残りを 1 行に並べ、幅に収まるまで末尾のクラスタを取り除く**（Android の `ellipsize="end"`、Flutter と同じ）。1 行でも複数行でも同じ規則で、行が幅いっぱいまで埋まる。

### 2. 飾りの文字

- **(a) `Text` / `RichText` に `Decorative bool` を足す。** `Text` しか隠せない。飾りの `Container` の中の文字や、自作の部品には使えない。
- **(b) 配下を Semantics から外す汎用の部品を足す**（Flutter の `ExcludeSemantics`、Web の `aria-hidden`）。core にはすでに仕組みがある。RenderObject の `Semantics(sb)` は子を `sb.Visit` するかどうかを自分で決めるので、子を訪ねない RenderObject を置くだけでよい。`core.Hider`（ADR 0120 の `BlockSemantics` の前提）はヒットテストとフォーカスからも外すので、目的に合わない。

### 3. VStack / HStack

- **(a) そのままにして、間隔が無いことを godoc に書く。** 補助関数を使う人ほど godoc を読まない。既定の見た目が詰まったままになる。
- **(b) 既定の間隔を持たせる。** 補助関数は `ctx` を受け取らない 1 行の関数なので、実行時のテーマではなく定数 `theme.Space8` を使う。DESIGN.md は「コントロールの間は 8、セクションの間は 24」としている。補助関数で積むのは数個のコントロールが多いので 8 を選ぶ。関数オプションは足さない（CODING_STYLE §5.3）。ほかの間隔は `Column` / `Row` を書く。

## 決定

1(b) と 1(ii)、2(b)、3(b) を採った。

### 1. text.Style.MaxLines

- `Style.MaxLines int`。ゼロは無制限。段落全体の設定で、`Span` の `Style` では無視する。`WithMaxLines` を足した（よく変える値なので ADR 0031 の `With` の対象に入れる）。
- `Paragraph.Layout` は、行数が `MaxLines` を超えた時点で残りのブロックの行分割をやめ、`truncate` を呼ぶ。最初の `MaxLines-1` 行は切り詰めない場合と同じである。
- 最後の行は、その行の先頭から所属ブロックの終わりまでを、幅を無限にした `jlreq.Breaker.Break` で 1 行に並べ直す（字詰め・和欧間・括弧の詰めは同じ規則で付く。両端揃えはしない）。そのうえで、末尾のクラスタを 1 つずつ取り除き、「行頭からの長さ + 省略記号の送り」が幅以下になる所で止める。クラスタは書記素クラスタ（合字・ルビのグループを含む）なので、絵文字や結合文字が割れることはない。
- 取り除いた後、省略記号の前に空白と始め括弧（JLReq の行末禁則）が残れば、それも取り除く。行頭禁則の文字（句読点や閉じ括弧）は行末に来るので残してよい。
- 省略記号は「…」（U+2026）を、その前のクラスタの区間のスタイルで整形し、区間ごとに 1 回だけ作って `section` に持つ（ハイフンと同じ）。縦書きの段落では縦向きで整形されるので、フォントの `vert` によって縦の省略記号になる。前のクラスタが変わって区間が変われば測り直す。切る位置は後ろにしか動かないので終わる。
- 省略記号は論理上の末尾に置き、見た目の位置は段落の向きに従う。左から右の行では最後のクラスタの後ろ（BiDi で並べ替えた後の右端と同じ位置）、右から左の行では左端に置き、クラスタを省略記号の幅だけ右へずらす。行の中の BiDi の並べ替え（UAX #9 L1/L2）は切った後のクラスタでやり直す。
- 省略記号すら幅に収まらないときは、何も描かず空の行にする。幅を超えて描くことはない。
- 隠れるのが空の行だけのとき（末尾の改行など）は、行を落とすだけで省略記号は付けない。
- `Layout.Truncated()` で切り詰めたかを返す。残りをツールチップで見せるときに使う。
- `Relayout`（エディタ用の差分レイアウト）は、`MaxLines` があれば全体の `Layout` に回す。

### 2. interact.ExcludeSemantics

- `layout.RenderExcludeSemantics` は `RenderProxy` を埋め込み、`Semantics` で子を訪ねない。レイアウト、描画、ヒットテスト、フォーカスは変わらない。core には手を入れない。
- `interact.ExcludeSemantics{Child}`。`interact.Semantics` の隣に置く。ゼロ値でも子を外す（外さないなら置かなければよいので、切り替えのフィールドは持たない）。
- `basic.Text` の godoc に、全文が読まれること、飾りの文字はこれで囲むことを書いた。中に操作部品を置くと、Tab では届くのにスクリーンリーダーからは見えなくなるので、godoc で禁じた。

### 3. VStack / HStack

- `VStack` は `Column{Size: MainMin, Spacing: theme.Space8}`、`HStack` は `Row{Size: MainMin, Spacing: theme.Space8}` を返す。交差軸は従来どおり始端揃え（ゼロ値の `CrossStart`）。
- 設定画面のレシピ（グループとボタン）は、セクションの間の `theme.Space24` を空けた `Column` に書き換えた。カウンターなど、残りの `VStack` の呼び出しは 8 の間隔でそのまま見られる形だった。

## 結果

- `Text{Style: th.Text.Body.WithMaxLines(1)}` で、フォントや言語によらず幅に収まるプレビューが作れる。スクリーンリーダーと `gowakutest` の `Find` は全文を読む（`RenderParagraph.Semantics` のラベルは整形前の全文のまま）。
- 切り詰めは行分割のとき（幅が変わったとき）だけ動く。同じ幅での再レイアウトは `RenderParagraph` が前の結果を使うので、定常状態のアロケーションはゼロのまま（テストで確認）。省略記号の整形は区間ごとに最初の 1 回だけ。
- 切り詰めた行に対するヒットテスト、キャレット、選択の矩形は、残したクラスタの範囲で返る。`SelectionArea` でドラッグして選べるのは見えている部分までで、全選択（文字列の末尾まで）では隠れた部分もコピーされる。
- `ExcludeSemantics` は `Icon` / `Image` の「Label が空なら飾り」と同じ考えを、任意の部品に広げる。
- `VStack` / `HStack` を使っていた既存の画面は、子の間に 8 の間隔が入る。間隔の無い積み方が要る所は `Column` / `Row` を書く。
- 未解決: 中間の省略（「始め…終わり」、ファイルパス向け）や、行頭側の省略は扱わない。必要になったら `Style` に切り詰め方の列挙を足す。
