# 0035: 見本アプリを新しい API に移して見つかった点を直す

決定日: 2026-11-08

状態: 採用

## 背景

ADR 0027〜0034 の API で 音楽プレーヤーの見本アプリを書き直したところ、次の点が見つかった。

1. **隠れたあともフォーカスが残る。** フォーカスを持った部品が不透明度 0 になっても、フォーカスがそのまま残った。そのため、見えないボタンを Space で押せた。次の Tab は、位置が分からず窓の先頭に戻った。ADR 0027 は Tab の巡回から隠れた部品を外したが、すでに持っているフォーカスは扱っていなかった。
2. **標準のフォーカスの輪をアプリから描けない。** 描く部品（`focusRing`）が `widgets` の中に閉じていた。そのため、`Pressable` で作る部品は、アプリごとに違う輪を自作していた。
3. **入れ子の `Pressable` が書けない。** 内側の部品がフォーカスを得たことを外側が知る手段も、内側を Tab の巡回から外す手段もなかった。
4. **`WithSize` で行が格子から外れる。** `LineHeight` は文字の大きさに対する比なので、`Section`（12px、行 18px）に `WithSize(11)` を使うと、行が 16.5px になった。テーマが約束する偶数の行から外れ、ListView の行の高さを手で 41.5 と書く羽目になった。
5. **細かい点：**
   - `WithAlign` がない。
   - `Container.Border` は `*paint.Stroke`、`AnimatedContainer.Border` は `paint.Stroke` で型が違う。
   - ListView の見出しを上に固定する方法が書かれていない。

## 選択肢と決定

### 1. 隠れた部品のフォーカス

- (a) 隠れたら Tree が気づいてフォーカスを外す。隠れるのはアニメーションの途中でも起きるので、毎フレームの Build の最初と、キーを配る前に、フォーカスから親へたどって確かめる。深さ分の比較だけで済み、アロケーションはない。
- (b) キーを配るときだけ確かめる。`FocusChanged(false)` が遅れるので、`PressState.Focused` が立ったままの見た目が残る。

**(a) を採る。** 外したフォーカスは anchor として覚えておき、次の Tab はその位置から進む。隠れた部分木の中も、anchor の位置を探すためだけにたどる。同じ処理で、`CanFocus` が偽になった部品（無効になった、`SkipTab` になった）からもフォーカスを外す。

### 2. フォーカスの輪

`widgets.FocusRing{Visible, Radius, Color, Child}` を公開する。コントロールと同じ 3px の輪を出し、同じ速さで表示と非表示を切り替える。`Color` のゼロ値はテーマの `AccentInk`。透明度は輪の側で決める。

### 3. 入れ子の Pressable

`Pressable` に次の 2 つを足す。

- `OnFocusChange func(bool)`：外側が、内側にフォーカスがある間も表示を保てる。
- `SkipTab bool`：ポインターだけで届く領域にする。

Flutter の `Focus.onFocusChange` と `canRequestFocus` に当たる。`FocusWithin` のような木の問い合わせは、今回は足さない。

### 4. WithSize と行の高さ

- (a) 行を px で持つように `text.Style` を変える。公開 API の意味が変わり、組版のすべてに響く。
- (b) `WithSize` が行を px のまま保つ。新しい大きさの 1.2 倍より詰まる場合だけ、比のまま広げて偶数 px に切り上げる。
- (c) doc に注意書きだけを書く。

**(b) を採る。** 小さくする場合は、ロールの格子に必ず残る。大きくする場合も、偶数の行に揃う。`LineHeight` のゼロ値（既定の 1.5）はそのまま。あわせて、行の高さを px で返す `Style.LinePixels()` と `WithAlign` を足した。

### 5. Border の型

`Container.Border` を `paint.Stroke` の値にする。幅 0 のゼロ値は線なしを表す。v1 はまだタグを打っていないので、リポジトリ内の呼び出し 8 か所を書き換えた。

### 6. 見出しの固定

ListView に固定の見出しの機能は足さない。見出しを ListView の上に置き、ListView を `Expanded` に入れれば固定になる。この書き方を `ListView` の doc に書いた。

## 影響

- 隠れた部品、または使えなくなった部品からはフォーカスが外れ、`FocusChanged(false)` が呼ばれる。
- `WithSize` の行が変わる。見本アプリ では、文字を小さくした所の行がロールの行に揃った。
- `Container{Border: &paint.Stroke{...}}` は `Container{Border: paint.Stroke{...}}` と書く。
- 見本アプリ は自作の輪、固定値 41.5、`alignEnd` を捨てた。アルバムのタイルは、キーボードでも再生ボタンまで届くようになった。
