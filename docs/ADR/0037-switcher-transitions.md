# 0037: AnimatedSwitcher の動きを選べるようにし、Translate を足す

決定日: 2026-11-08

状態: 採用

## 背景

ページを切り替えるときにアニメーションさせたい、という要望が出た。これまでの `AnimatedSwitcher` はクロスフェードしかできず、`Opacity` で決め打ちされていた。設定できるのは `Duration`、`Curve`、`Alignment` だけだった。また、子をずらして描くウィジェットがなく、スライドを書く手段もなかった。

## 選択肢と決定

### 動きの指定

- (a) 動きの種類を列挙型で選ぶ（`TransitionFade`、`TransitionSlide` …）。選べるのは用意したものだけになり、向きや距離の引数が増え続ける。
- (b) Flutter の `transitionBuilder` と同じく、関数で包ませる。`SwitcherTransition func(child Widget, t float32, entering bool) Widget` で、`t` は入ってくる子では 0→1、出ていく子では 1→0 に動く（`Curve` を掛けたあとの値）。

**(b) を採る。** よく使う形は関数として用意する。

- `FadeTransition`：既定のクロスフェード。
- `SlideTransition(dx, dy)`：入ってくる子は (dx, dy) から元の位置へ、出ていく子は逆向きの (−dx, −dy) へ動き、どちらもフェードする。
- `ScaleTransition(from)`：拡大縮小とフェードを組み合わせる。

新旧どちらの子にも、いちばん新しいウィジェットの `Transition` を使う。こうすると、切り替えた時点で選んだ向き（次のタブなら左へ）が、新旧の子にそろって効く。返すウィジェットの型は `t` によって変えてはいけない。変えると、動きの途中で子の State が作り直されてしまう。これはテストで確かめた。

### ずらす部品

`Translate{X, Y, Clip}` を足す。ずらす量は子の大きさに対する割合で指定する。`Scale` と同じく、ずらすのは描画だけで、レイアウト、ポインター、Semantics は元の位置のまま扱う。動きの途中だけ使い、最後は 0 に戻す前提にした。ヒットテストまでずらすと、イベントの局所座標をすべて直す必要があり、遷移の 200ms のためには割に合わない。

`Clip` は、自分の箱の外に描かせないための指定で、スライドするページが隣のサイドバーに掛からないようにする。クリップ用のウィジェットはまだないので、ここに持たせた。

## 影響

- `Transition` を指定しない `AnimatedSwitcher` は、これまでと同じクロスフェードになる。
- 見本アプリ は、ページを切り替えると幅の 4% だけスライドしながらフェードする。サイドバーの順で後ろのページへ進むときや、アルバムの中に入るときは左へ、戻るときは右へ動く。
