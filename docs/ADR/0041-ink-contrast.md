# 0041: 読める文字色は Ink と Ink2 の 2 段にし、Ink3 は薄い色として残す

決定日: 2026-11-08

状態: 採用

## 背景

gowaku-preview のコントラストの警告（ADR 0040）を 見本アプリ にかけたところ、`Ink3` で書いた時刻、グラフの目盛り、順位の数字が、ライトで 2.5:1、ダークで 3.5:1 しかなかった。WCAG 2 が求める 4.5:1 に届かない。

そこで、`Ink3` をどこまで濃くすれば足りるかを計算した。調べた面は、Canvas、Sidebar、Card、Raised、Field と、それぞれにホバーの `Fill` を重ねたもの。結果は次のとおり。

- `Ink2` ですら、ライトで 4.53:1（ぎりぎり）、ダークではホバー中の Raised の上で 4.18:1 と、基準を下回っていた。
- 4.5:1 を満たす `Ink3` は、ライトで濃さ 42 以下になる。これは `Ink2` と同じ濃さである。

**`Ink2` より薄く、しかも 4.5:1 を満たす 3 段目の文字色は作れない。**

## 選択肢と決定

- (a) `Ink3` を読める濃さにして、無効の部品や飾りのために `InkFaint` を足す。`Ink2` と `Ink3` がほぼ同じ色になり、段階の意味がなくなる。
- (b) `Ink3` は薄い色として残し、情報を伝える文字には使わない、と決める。

**(b) を採る**（ヒアリングで決めた）。

- **`Ink3`：** これまでどおり、プレースホルダー、無効の部品、飾り（スクロールバーのつまみ、グラフの補助線、空の画面のアイコン）に使う。無効の部品は、WCAG のコントラストの基準の対象外である。「情報を伝える文字には使わない」と doc と DESIGN に書いた。
- **ダークの `Ink2`：** 濃さを 68 から 72 に上げ、ホバーを含むすべての面の上で 4.5:1 を満たすようにした。ライトの `Ink2`（42）は 4.53:1 でそのまま満たしている。
- **テスト：** `TestColors_InkReadsOnEverySurface` を足した。アクセントの色を 5 つ変え、ライトとダークのそれぞれで、`Ink` と `Ink2` が全部の面で 4.5:1 以上であること、`Ink3` がそれを下回る（薄いままである）ことを確かめる。

## 影響

- ダークの補足の文字が、少し明るくなる。ピクセルの golden（CPU、D3D11、Vulkan）は、ダークの `Ink2` を含まないので変わらなかった。
- 見本アプリ では、文字に使っていた `Ink3` を、すべて `Ink2` に替えた（セクション名、時刻、件数、ヒント、表の見出し）。飾りの 2 か所（グラフの平均線、検索結果が空のときのアイコン）は `Ink3` のまま残した。プレビュー 14 枚の警告は 0 になった。
