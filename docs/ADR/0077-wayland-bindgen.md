# 0077: gowaku-bindgen（Wayland のバインディング生成）の公開

決定日: 2026-11-10

状態: 採用

## 背景

Phase 10 で、Wayland のプロトコル XML から purego のバインディングを生成する内部ツール `internal/cmd/wlgen` を作った（ADR 0021）。検討して次のように決めた。

- Wayland 版だけを `cmd/gowaku-bindgen` として公開する。利用者がコンポジタ固有のプロトコルを自分で生成できるようにするため。
- Vulkan のバインディングは手書きのままにする。vk.xml の生成器は作らない。

ただし、生成されたコードは `platform/wayland` の非公開の名前（`conn`、`wlInterface`、`unsafe` を使う `cstr` など）だけで書かれていた。だから `platform/wayland` の中にしか置けなかった。

## 決定

### 1. 1 つの生成器から 2 つの出力の形

- **パッケージ内の形**（`-runtime=` を空にする）: 今までと同じ出力。差は見出しの行（`Code generated by gowaku-bindgen`）だけ。gowaku 自身の `platform/wayland` はこれを使うので、ホットパスは何も変わらない。
- **外部の形**（既定。`-runtime` の既定は `github.com/bankai-tensei/gowaku/platform/wayland`）: `platform/wayland` を `wl` として import し、公開した実行時の API を呼ぶ。利用者のパッケージに置ける。
  - 出力には `unsafe` も NUL のリテラルも出ない（テストで確かめている）。だから depguard（unsafe は platform の中だけ）を守ったまま、利用者のコードに入れられる。

### 2. platform/wayland に足した公開 API（`extension_linux.go`）

- 型: `Proxy`、`Interface`、`Message`、`MarshalDestroy`。
- `(*Interface).Set(name, version, requests, events)`: wl_interface の表を Go のメモリに作る。文字列は NUL 付きで写して持ち続ける（ADR 0021 と同じ理由）。シグネチャと Types の数が合わなければ panic する。
- `Conn`: 引数は型付きのセッター（`SetInt`、`SetString`、`SetObject`、`SetNewID` …）と `Marshal`。生の uint64 は外に出さない。
- イベント: `Args` と、ジェネリックな `Listen[L any](c, p, l, dispatch)`。API に `any` の引数を出さない（CODING_STYLE §14）。Listen のたびに 1 回アロケーションし、イベントごとにはしない。
- `Platform.Conn()`、`Platform.Globals()`（レジストリが全グローバルを覚え、global_remove で消す）、`Platform.Bind(g, in, version)`（要求した版とコンポジタの版の小さい方で bind する）。
- ウィンドウの wl_surface は `NativeHandle()` の `Surface` から `wayland.Proxy` として得る。専用の取得関数は足していない。
- 利用者のバインディングは Platform の接続、レジストリ、1 つのディスパッチャを共有する。だからイベントは WaitEvent に届き、purego のコールバックは増えない。ADR 0021 の設計のままである。

### 3. 採らなかったもの

- **非公開の名前をそのまま公開する**: unsafe と生の uint64 が API に出る。
- **`platform/wayland` を写したフォークに生成させる**: モジュールの外では現実的でない。
- **wl_display を公開して、利用者が自分のキューや接続を開く**: 利用者のコードに purego と unsafe が要り、depguard が禁じる。
- **主要インターフェイス（wl_surface など）の公開済みの表**: 利用者が wayland.xml から自分で生成できるので、先送りした。libwayland はインターフェイスを名前で比べるので、それで動く。

### 4. その他

- フラグ: `-out`（必須）、`-pkg`（旧 `-package`。既定は出力先のディレクトリ名）、`-runtime`、`-table`、`-tags`、`-skip`。
- 入力に無いインターフェイスの new_id はエラーにする。今までは黙ってコンパイルできないコードを出していた。
- 使い方は `cmd/gowaku-bindgen/README.md`（日本語）にある。架空のプロトコル `testdata/example-shortcut-v1.xml` で、生成から bind までを通して示した。

## 残したこと

- **`gowaku.Run` のアプリからは使えない**: Run は platform を内部で開くので、アプリは `*wayland.Platform` を受け取れない。今は `wayland.New()` で自分のループを回すプログラムだけが使える。Run の中に platform を渡すフックを足すかは、レビューで決める。
- null の文字列は送れない（"" になる）。後から現れたグローバルの通知は無い。生成した名前は非公開。
