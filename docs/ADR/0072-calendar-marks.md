# 0072: カレンダーの日の印

決定日: 2026-11-09

状態: 採用

## 背景

`widgets.Calendar` には Value、Today、Min/Max、Selectable、OnChange があるが、日に印を付ける手段が無かった。予定のある日の下に点を出したいというサンプルアプリ（スケジュール）の要望があった。

## 決定

### 1. API

- `Calendar.Marks func(day time.Time) []geom.Color` を足した。返した色の点を、日の数字の下に横に並べて描く。nil か空なら描かない。
- `day` は Selectable と同じく、OnChange が使う zone の真夜中。
- `DatePicker.Marks` も足し、ポップアップのカレンダーにそのまま渡す。
- 名前は、点の色を返すことが分かる `Marks` にした。`Events` は予定以外（締め切り、休み、記録のある日）に使いにくい。

### 2. 点は 3 つまで、4 つ目以降は捨てる

- 先頭の 3 色だけ描き、残りは描かない。「3 つ目が『もっとある』を表す」案は採らなかった。
  - 3 つ目の色が利用者の意図した色でなくなり、色の意味が日によって変わる。
  - 「もっと」を表す専用の形（＋や省略記号）は 4px の点では読めない。
  - 何を先に並べるかは利用者が決められる。doc コメントに「大事なものを先に」と書いた。
- 透明（A が 0）の色は飛ばす。空きの点を作らないため。

### 3. 寸法

- 点は直径 4、間隔 2。中心はセルの下端から 6（`calendarDotBottom`）。
- セルは 32、数字の行は 20 なので、数字の下に 3px ほど空き、選んだ日の円（半径 16）の内側に 3 つとも収まる（テストで確かめている）。
- 印のある日も数字の位置は変えない。日によって数字が上下すると、列がそろって見えない。

### 4. 色

- 普通の日と今日は、利用者の色のまま描く。doc コメントでは、Canvas と Card の上で読める色（`AccentInk`、`Danger`、`Success`）を勧めた。`Accent` は塗り用で、ダークでは暗く沈む（スクリーンショットで確かめた）。gallery も `AccentInk` を使う。
- 選んだ日（アクセントの塗り）では、点を数字と同じ `OnAccent` にする。色の区別は消えるが、アクセントの上で利用者の色が読める保証は無い。輪を付ける案は 4px では濁るのでやめた。
- 選べない日と月の外の日は、数字と同じ `Ink3` にする。数字が沈んでいるのに点だけ色を持つと、そこだけ目立つ。無効の calendar で選ばれた日（`FillStrong` の地）も `Ink3`。
- 半透明で薄める方法は使わない。DESIGN §5「無効はトークンで描く」に合わせた。

### 5. アクセシビリティ

- 印のある日は、スクリーンリーダーに日付の後に `Strings.Marked` を読ませる。英語 "has events"、日本語「予定あり」。ラベルは `SpokenDate + ", " + Marked`。
  - 予定以外の印に使うアプリは、自分の Strings で Marked を差し替える。
  - 色や点の数は読ませない。色の意味はアプリにしか分からない。
- Hint ではなくラベルに足した。Hint は「使うと何が起きるか」で、印は日の状態だから。
- `Strings` に足した語は fillFrom にも足したので、Marked を持たない表は英語になる。

### 6. いつ呼ぶか、アロケーション

- Marks は Build で、見えている 42 日に 1 回ずつ呼ぶ。Paint では呼ばない（テストで確かめている）。ホバーなどで build し直すたびに 42 回呼ばれるので、軽い関数にすることを doc コメントに書いた。
- calendar は返したスライスを持たない。色は `face` の固定長配列 `[3]geom.Color` に写すので、関数は毎回同じ配列を返してよい。
- Paint は配列をなめて角丸矩形を描くだけで、0 allocs/op（`BenchmarkCalendar_PaintMarks`）。
- 結果をキャッシュしなかった。月をめくるたびに捨てることになり、関数が別の値を返すようになったときの無効化の仕組みが要る。42 回の呼び出しは build の他の仕事（日付の文字列）より軽い。

## 残したこと

- 1 日に 4 つ以上の印があることを、目で知らせる手段は無い。要るなら、点の代わりに数を出す別のフィールドを考える。
- 印の意味の凡例は calendar の外でアプリが出す。
