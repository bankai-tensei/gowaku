# 0055: ツールチップ、トースト、シート（15a）

決定日: 2026-11-09

状態: 採用

## 背景

ADR 0053 の 15a のうち、一時的に出る 3 つ。どれも Overlay の上に出る。

## 決定

### 1. 面

**ツールチップとトーストは、黒地の反転面にしない。** `Raised` に Hair の線を引く。影は、ツールチップが LiftKnob、トーストが LiftFloat。反転面は DESIGN に無いトークンで、画面の中で一番目立ってしまう。浮く面の言語をメニューやダイアログとそろえた。

### 2. Tooltip

- ポインタが 500ms 留まると出る。前のツールチップが閉じてから 1 秒以内に別のものへ移ったときは、待たずに出す。
- キーボードでフォーカスが来たときはすぐに出す。押下でフォーカスが来たときは出さない。
- ポインタが離れたとき、押下、ホイール、Escape で閉じる。押下と Escape で閉じた後は、ポインタが一度離れるまで出し直さない。
- 子の下に中央揃えで出し、窓の下端では上に反転する。
- 文は `RoleTooltip` のノードに載せ、子のノードの Hint にも入れる（`SemanticsBuilder.Describe`）。

### 3. Toast

- `ShowToast(ctx, Toast{Message, Action, OnAction, Duration}) (dismiss func())`。下中央、窓の端から 24 に積み、新しいものを下に足す。左右の向きに左右されず、視線が戻る位置だから。同時に出すのは 3 件までで、4 件目が来ると一番古いものが消える。
- Duration（既定 4 秒）は、ポインタが載っている間とフォーカスが中にある間は数えない。
- 入りは 280ms の SpringOut、出は 160ms。枠の高さとフェードを 1 本のコントローラで動かすので、新しいトーストが来ると古いものが滑らかに押し上がる。ReduceMotion ではフェードだけにする。
- **読み上げ**: UIA は、新しく現れた live ノードを読み上げず、ラベルの変化だけを読む。そこで RoleGroup + LivePolite のノードを、最初のフレームは空のラベルで出し、次の tick でメッセージを入れる。live ノードはフェードの外に置く（Opacity 0 は Hider としてノードごと隠すため）。

### 4. Sheet

- `ShowSheet(ctx, Sheet{Edge, Size, Label, Persistent}, build)`。下からと横から（`SheetBottom` / `SheetTrailing` / `SheetLeading`）出る。ShowDialog と同じ形の API。
- 下のシートは最大幅 640 で、高さは内容に合わせる。横のシートは幅 320。どちらも窓の 9 割まで。`Raised`、Lift 3、余白 24。
- 角丸 16 は見える角だけに付ける。窓の端側の角は窓の外へ 16 はみ出させて隠す（Decoration の角丸は全角共通なので、layout を変えずに済む）。
- フォーカスを閉じ込め、Escape で閉じ、閉じたらフォーカスを開いた元へ返す。`Persistent` でなければスクリムのクリックでも閉じる。退場は 160ms で、ダイアログの 120ms より長い（動く距離が長いため）。ReduceMotion では滑らせず、その場でフェードする。

### 5. core と Overlay に足したもの

- `core.FocusWithinListener`: フォーカスが子孫に入ったことと出たことを、変化した側の祖先に知らせる。ツールチップをキーボードで出すのと、フォーカス中のトーストを止めておくのに使う。アロケーションは無い。部品が外れたことでフォーカスが外れる場合は知らせない（外れる途中の SetState を避けるため）。
- `core.SemanticsBuilder.Describe(hint)`: 次に開くノードの Hint が空なら hint を入れる。
- **Overlay のエントリが窓全体の押下を取っていた**: エントリの RepaintBoundary はオーバーレイ全体を覆い、既定の HitTest で全部の押下を取っていた。そのため、ツールチップやトーストを出している間、窓のほかの部分を押せなかった。中身が何もヒットしなければ下へ通すようにした。Dialog とメニューは全面の barrier を持つので、挙動は変わらない。
- 窓ごとに共有する状態（ツールチップの「温まり」、トーストの置き場）は、パッケージ変数ではなく `OverlayState` のフィールドに持つ。

## 結果

- golden は `tooltip`、`toasts`、`sheet-bottom`、`sheet-trailing`（それぞれライトとダーク）。
- gallery の「表示」のページで、トーストとシートを出せる。UIA では、トーストが「保存しました」のグループとして、アクションのボタンと一緒に見える。
- 残り: 「空ラベルの後に変える」方法で、Narrator / NVDA が実際にトーストを読み上げるかは、耳で確かめていない。横のシートの Leading / Trailing は左右に固定で、書字方向には追従しない。
