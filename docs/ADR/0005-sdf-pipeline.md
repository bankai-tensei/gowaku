# 0005: SDF パイプラインのインスタンス形式と描画の意味

決定日: 2026-11-07

状態: 一部を ADR 0032 で置き換え

## 背景

Phase 1 で描画パイプラインの最初の段階（P1）を実装した。当初の計画に書かれていない形式と、書かれていたが実装の都合で変えた点を残す。

## 決定

### インスタンスは 112 バイト、頂点バッファなし

> 追記（2026-11-08）: ADR 0032 で末尾に中間色 2 つとストップ位置 4 つを足し、160 バイトになった。既存のフィールドのオフセットは変わらない。

`gpu.Instance` は矩形、四隅の半径、色 3 つ、グラデーションの制御点、ボーダー幅、ブラー、種類の 112 バイト。四角形の角は `SV_VertexID` から導き、4 頂点の三角形ストリップを `DrawInstanced` で描く。全バックエンドのシェーダーがこの形式に従う。

### ボーダーと塗りは 1 つの Paint で同時に描く

当初の計画の `Stroke *Stroke // nil なら塗り` は「塗りか線か」の二者択一に読める。一方、同じ計画の末尾には「ボーダーは 1 矩形 = 1 インスタンス」とあり、両立には塗りとボーダーの同時指定が要る。そこで `Stroke{Width, Color}` に色を持たせ、`Paint.Color` が透明なら線だけになる形にした。ボーダーは形の内側に描く（CSS の `box-sizing: border-box`、Flutter の `Border` と同じ）。

### シェーダーの内部は premultiplied

API の色は当初の設計の決まりのとおり非 premultiplied のまま。シェーダーの中で premultiplied に変換し、ブレンドは `ONE, INV_SRC_ALPHA` にする。非 premultiplied のままカバレッジで塗りとボーダーを混ぜると、半透明の境界で色が滲むため。合成が sRGB のままである点は変えていない。

### グラデーションは 2 色

> 追記（2026-11-08）: ADR 0032 で、インスタンスの中に最大 4 ストップを持つ形に置き換えた。下の判断は当時のもの。

複数ストップにはインスタンス外のデータ（テクスチャか配列）が要る。v1 のウィジェットで必要になるまで作らない。

### 影は 6 サンプル、誤差 2% 以内

Evan Wallace の方法は片方の軸を解析的に、もう片方を標本化する。サンプル数は真のガウスぼかし（`TestShadow_MatchesTrueGaussianBlur` が float64 で素朴に計算する）との誤差と、最悪ケース（1 万矩形すべてに影、Iris Xe、1800×1020）の速度で決めた。

| サンプル数 | 最大誤差 | fps |
|---|---|---|
| 4 | 3.6% | 180（1 回の計測） |
| **6** | **1.7%** | **120〜150（5 回の計測）** |
| 8 | 1.1% | 119（1 回の計測） |

Iris Xe の fps は実行ごとにばらつき、120 や 180 のように 60 の倍数に張り付くことがある。原因は未調査で、表示側のペーシングの影響と見ている。

誤差は不透明な黒の影に対する値で、MD3 の影（α 0.3）では 2/255 未満になる。最大誤差が出るのは小さなぼかしの形の縁で、普通はその上に形自体を描くので隠れる。許容値は当初 1.5% としていたが、6 サンプルを採用するにあたり 2% に改めた。

影の角丸は四隅の最大値で近似する。四隅が異なる形の影は少し丸くなる。

### クリップはシザーのみ、変換は平行移動のみ

`ClipRRect` と `ClipPath` はステンシルが要るので Phase 5。`Canvas.Transform` は SDF をアフィン変換に対応させる必要があるので、スケール遷移を作る Phase 6 で入れる。

### 計測用に `PresentImmediately` を持つ

`Present(0, 0)` はフリップモデルでは DWM に律速されて 60fps で止まり、処理能力を測れなかった。`DXGI_PRESENT_ALLOW_TEARING` を使う計測専用のオプションを置く。

## 結果

- CPU 側の Canvas 記録と Encode は 1 万インスタンスで合わせて約 0.5ms、アロケーションは 0。
- シェーダーの結果はブラウザの `box-shadow` と見分けがつかない（同じ図形をブラウザで描いた画像と並べて比べた）。
- Vulkan バックエンドは Phase 7 で同じ `sdf` シェーダーを GLSL に書く。`gpu.Instance` の変更は両方の修正を伴う。
