# gowaku ガイド

[English](../en/README.md)

gowaku でデスクトップアプリを作る方法を、最初のウィンドウを開くところからパッケージ化まで順に説明する。最初は上から順に読み、その後は必要な章だけ開けばよい。個々のウィジェットとそのフィールドについては、[ウィジェットカタログ](../../catalog/ja/README.md)とパッケージのドキュメントを参照するとよい。

| ガイド | 内容 |
|---|---|
| [はじめに](getting-started.md) | 動作環境、インストール、最初のウィンドウ、カウンター、サンプル。 |
| [基本の考え方](concepts.md) | Widget・Element・RenderObject、State と `SetState`、`BuildContext`・継承データ・キー、変更が画面に反映されるまでの流れ、操作がないときに何も描画しない仕組み。 |
| [レイアウト](layout.md) | 制約のプロトコル、行・列・重ね合わせ・折り返し・グリッド・スクロール・リスト、独自レイアウトの書き方。 |
| [テーマ](theme.md) | アクセントカラー 1 色、ライトとダーク、実行中のテーマ変更、文字スタイルとトークン、独自のトークン。 |
| [モーション](motion.md) | 暗黙アニメーション、子の切り替え、カーブ、コントローラ、スプリング、ページ遷移とヒーロー。 |
| [文字と IME](text-and-ime.md) | 文字スタイル、日本語組版、ルビ、縦書き、入力メソッド。 |
| [アクセシビリティ](accessibility.md) | スクリーンリーダー、Semantics、フォーカスとキーボード操作。 |
| [ウィンドウと OS](windows-and-os.md) | ウィンドウ、モーダルウィンドウ、メニュー、タイトルバー、クリップボード、ファイルダイアログ、ドラッグ＆ドロップ、トレイと通知。 |
| [テストとプレビュー](testing-and-preview.md) | ウィンドウを開かずに `go test` の中でツリーを動かす方法と、保存のたびに再描画するプレビュー。 |
| [パッケージ化](packaging.md) | アプリのアイコンとメタデータ。 |
| [プラットフォーム](platforms.md) | OS ごとの必要環境と対応機能、既知の制限。 |
| [よく使う形](recipes.md) | 一覧と詳細、確認付きの設定画面、長い縦書きの文章、バックグラウンドの処理を、完成したプログラムで示す。 |
